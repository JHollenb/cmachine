Use the actual approximate reader operands rather than treating native Q as the optimal target. Keep separate source trajectory clocks, native bias, half-split RoPE, prototype count mass and native values. A single response-gradient direction with a source-only dose panel is the smallest informative change. Pull the gradient through the transpose rotation, precondition retained coordinates, and use the Jacobian's predicted curvature to set the line scale. Keep every proposal, including wrong sign and zero dose.

The source teacher is reconstructed CPU64 attention, not captured CUDA output. Downstream C own-history tests are the authority on transfer.
