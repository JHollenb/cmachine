# Query qualified memory through its own transitions

November 6, 2026. A prospective development experiment following the holistic review. Original Qwen2.5-1.5B-Instruct, C FP32 CUDA/cuBLAS, batch one, capacity512, CPU1. Native projection weights and all nonlinear model operations remain. There is no training, serving promotion or speed claim.

## Hypothesis and alternatives

A small support selected by a receiver's own query may preserve consequential distinctions that a similarly small recent window loses. Lower-precision paired rows may preserve more response information than aggressive support reduction. A correct state-management loop alone does not settle either question.

The primary organism is the frozen four-corner initial-binding by update square in `inputs.json`. Two named people initially receive opposite colors; they subsequently retain or exchange badges. Each policy begins at empty state, consumes its own short acknowledgements, a fixed distractor and then two independent question forks. Each question asks one person's final color. The first question's answer never enters the second parent. Final assignment is the XOR of initial and update bits. Preserve each corner: swap failures may concern the update computation rather than forgetting.

All prompts, support size4, budgets4 per acknowledgement and8 per answer, numerical policy and analysis are frozen before model execution. The text panel is not selected for native success. Wrong native answers, losing deletion controls, incomplete answers and generated-token divergence remain observations and instrument diagnostics; they do not stop the other cases.

## Policies

1. Native FP32 full causal memory at all28layers.
2. Paired signed-byte full memory at all28layers.
3. The same byte representation with a current-query top-four attention read. Select independently per query head, preserve GQA mapping, deterministic ties and absolute positions. Retain and scan all valid keys.
4. Byte recent-four ring storage/read at all28layers. Retain the latest four positioned pairs per layer. Count checkpoint and partial-token backup storage separately.
5. Historical-memory deletion on a native/FP32 parent. Form the record, update and distractor natively. At each question fork exclude all pre-fork rows from attention, preserving absolute clock and the complete newly appended question prefix. This paid diagnostic asks whether the questions depend on prior context; it is not another cheaper construction policy.

Top-four and recent-four match the maximum number of value rows mixed per head, not storage, selection work or total computation. Byte-full versus top-four isolates a policy contrast, not automatically one fixed-query intervention: lower-layer changes can alter higher-layer queries. Native versus byte-full likewise measures the composed codec policy.

The exact FP32 callback control must reproduce ordinary native logits/cache and token choices. Test append-before-current-read, common-parent independent query forks, sibling replay, and rollback after a partial multi-layer update. Ring snapshots must restore overwritten rows as well as cursors; cursor truncation alone cannot restore eviction. Count physical attempts even when logical state rewinds.

## Conditional response account

At selected first query readouts capture the candidate's actual query and audit-only original own-row K/V history at layers17/18. The audit history must not be available to the serving reader. After primary output sealing, evaluate original-own full response, decoded-byte full response and decoded-byte top-four response on those same operands. These diagnose codec and selection conditional on the actual query, separately from native-trajectory drift.

For S the selected support and T its complement, let epsilon be full attention mass on T. Then A=(1-epsilon)A_S+epsilon A_T and A-A_S=epsilon(A_T-A_S). Retain omitted mass, value contrast, signed error vectors, finite execution remainder, and every case. Small omitted mass alone does not guarantee small read error. Do not turn term norms into causal percentages.
