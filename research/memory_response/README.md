# Query qualified memory through its own transitions

This finite development experiment tests full paired memory, paired-byte memory, a fixed top-four reader, a recent-four ring and native-parent history deletion on a four-corner binding/update task. Every primary path starts from empty input and follows its own generated acknowledgements. Two later questions fork independently from that candidate's own parent.

The [hypothesis post](../../../obsidian/blog/2026-11-06-154253-a-hypothesis-for-cheaper-model-state-transitions.md), [prospective plan](PLAN.md), [Astra advisory](ADVISOR.md) and [literal task panel](inputs.json) state the mechanism question before results. Top-four and recent-four match attended support size, while their retained memory and selection cost differ. The native-parent deletion diagnostic preserves absolute positions and all newly appended query rows. Native projections and the rest of the model remain paid.

The experiment uses the exact Qwen2.5-1.5B-Instruct C FP32 CUDA/cuBLAS profile and the [owned-append runtime](../composition/compact_append/README.md) as its authenticated ancestor. It is isolated from installed serving. Runtime source, inputs, compiled executable, complete output vectors at declared boundaries and numerical analysis are frozen per submitted payload. Generated EOS is consumed once; ring checkpoints restore overwritten rows, not only cursor metadata.

`run.py stage-smoke` selects case0. `stage-panel` selects all four cases after the mechanics lane. `submit`, `collect` and `verify` operate on a payload or exact job/result directory. Run through `common exec` and mrun; no real-model local execution is part of this assay. `worker.py` tokenizes the literal text, authenticates source/model/tokenizer identities, executes one resident process, seals primary arrays, then runs saved-only analysis.

Scientific quality is recorded as observations. Native correctness, deletion sensitivity, per-corner swaps, local response errors and losing controls do not stop the other arms. Source identity, finite shape/device contracts, native callback parity, replay/abort and custody protect interpretation. General chat, fixed-size semantic memory, source-free operand formation and latency improvement remain outside this panel's claims.

The completed [findings](FINDINGS.md), [proofs](MATH.md), [Astra interpretation](REVIEW.md), [full panel](runs/job-ceab8d5c9869/report.json), [saved tables/figures](runs/job-ceab8d5c9869/presentation.json), [verification](runs/job-ceab8d5c9869/verification.json) and [instrument repair history](INSTRUMENT_REPAIRS.md) are available. Byte-full saves 68.9% of tracked session state and preserves local response more faithfully than either four-row rule. Native answers 4/8 and misses every exchange decision while retaining correctly signed update effects; byte-full/top-four each answer 5/8 without a correct exchanged pair. This is bounded memory-retention evidence, not semantic closure or forward-pass-free chat. The original prospective hypothesis is retained as `HYPOTHESIS.md` inside each immutable payload.
