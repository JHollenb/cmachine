### Almost invariant branch, changed complete state

The (+0.5,+0.5) receiver is approximately 1.5 times the original receiver. RMS normalization nearly removes that positive scale, leaving the MLP write almost unchanged. The residual addition retains the changed carry: `y'=1.5*r+m(r)` differs from `y=r+m(r)`. Consequently, the output changes 47.29%, current upper KV changes 18.40%, and the common next token's upper KV changes 4.22%. The held-native-write arm closely follows this control, while differing materially from dense execution on the nonradial doses. An invariant MLP branch therefore does not identify an invariant complete model state.

For zero epsilon, the next normalization has derivative `rho*diag(gamma)*(I-y*y^T/||y||^2)`. With y=r+m, projecting the carry orthogonally to y equals the negative projection of the MLP write. Changing the carry magnitude can therefore change its directional balance with a nonparallel write, which later key/value projections consume. The actual experiment retains epsilon and native arithmetic; this derivation explains a candidate mechanism rather than replacing the measured computation.
