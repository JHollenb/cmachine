# Which information must survive the next computation

2026-11-06. Exploratory, bounded local-interface test. No terminal certification or general compact-chat claim. This replaces an immediate gate-recurrence test with an explicit retained-state and omitted-information challenge.

## Questions and declared interface

For a full state S and input u, an exact retained state C supports a deterministic successor G precisely when C(S1)=C(S2) implies C(F(S1,u))=C(F(S2,u)) on the declared domain. A chosen observable additionally needs Y(S,u)=H(C(S),u). This experiment first tests the local MLP16 interface rather than claiming to encode the complete model state.

The compact interface is exactly16bytes: the three actually executed FP32 B3 QR coefficients and the actual native GPU FP32 RMS scale. Static weights, frozen basis/QR, layer16, model identity, profile and shape are bound program inputs. The full receiving vector, its omitted complement, gate/up correction images and dense K/V are not part of this16byte local code. Full residual/K/V remain in the host and are explicitly outside the compression claim.

The primary observable is the dense MLP write M(r), not r+M(r). Holding the residual skip fixed in the later native consumer prevents a trivial result from directly adding the changed input.

## Source and finite fiber construction

Use the already measured recall, arithmetic and prose final-query receivers from that assay. These are three known development points, not held-out conversation cases.

Let Q contain the stored three QR columns. They are not assumed perfectly orthonormal. Define b=Q(QᵀQ)⁻¹Qᵀr0 and e=r0−b. Choose v perpendicular to Q and e with ||v||=||e||. Then

$$
r(\phi)=b+e\cos\phi+v\sin\phi
$$

preserves Qᵀr and ||r|| in real arithmetic. Generate four deterministic directions and the fixed signed angle grid ±[1,.6,.3,.1,.03,.01,.003,.001] radians. Materialize each receiver as FP32. Recompute the actual historical sequential FP64 QR solve, cast its three coefficients to FP32, and evaluate rho with the unchanged GPU RMS kernel. Retain all candidates and their actual codes.

An exact fiber witness requires identical16code bytes and different receiver bytes. Near matches are a separate diagnostic. Before evaluating any candidate MLP output, choose the first source-code collision in descending absolute angle, direction0..3, then negative/positive sign order. Selection uses code equality and source geometry only. If a source has no collision, retain it as evidence-incomplete for this instrument; do not infer sufficiency. No output-based or logit-based search is allowed.

## Interpretation

An exact equal-code/different-write pair refutes sufficiency of this particular16byte local interface on the supplied intervention domain. It does not refute all compact encodings or establish natural-context frequency. Complement correction identifies a sufficient paid operand for this invocation; it does not establish a cheap update rule for that operand. Own-token continuation measures how the local distinction is consumed by the full-state host. A complete reduced chat state and its recursively closed update remain separate targets.
