# All-layer byte caches from token zero

The [findings](FINDINGS.md) extend [two-layer append](../compact_append/FINDINGS.md) to all 28 cache layers, with all three sessions starting empty. Native, exact FP32 callbacks and byte callbacks independently consume the source, their own reply, a correction, their own acknowledgement and three later user turns. No native prefix or generated token is supplied to a candidate.

The deterministic [allocation patch](runtime_patch.py) skips zero-sized dense K/V allocations. [cache.h](cache.h) owns all 28 arenas and shared decode scratch; [driver.c](driver.c) records all own K/V, four layers' queries, sparse ports, full logits, cursors and physical work. The parent CUDA codec/read equations remain unchanged and source-bound. Installed serving is unchanged.

Twelve model-free checks and C syntax pass. The C execution in [`job-bbd58171a613`](runs/job-bbd58171a613/report.json) completes all 15 turns and lifecycle checks, but the original worker fails during post-processing because a historical hash field changed names. The failed scheduler state, original source and report remain immutable. [repair_analysis.py](repair_analysis.py) authenticates every archived byte and permits only the one-expression field-name correction, then reanalyzes saved operands with zero model calls. [Verification](runs/job-bbd58171a613/verification.json), [reanalysis](runs/job-bbd58171a613/reanalysis.json) and [Astra audit](REVIEW.md) preserve that distinction. `run.py verify RESULT_DIRECTORY` repeats the qualified path.

All five answers match native; ten measured logit differences are 3.732–9.839%, and genuine early-layer routing errors remain. The [evidence sweep](index/job-bbd58171a613/evidence-verify.json) covers 43 derived observations and seven applicable predicates. Full weights and linear context growth remain; sufficient arbitrary chat and speedup are not established.
