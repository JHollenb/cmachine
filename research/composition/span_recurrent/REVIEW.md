# Astra review: recurring paired-byte memory

The existing user-requested Astra advisor reviewed the source-only design, staged implementation and completed saved evidence on November6,2026. Its main conclusion is bounded: keeping paired atoms at reduced precision substantially improves recurring response fidelity over centroid aggregation at similar stored size. This is a standard compressed-KV baseline, not a new semantic law or proof of sufficient chat state.

Pre-submit review found no blocker in byte layout/scales, current-query prediction, direct workspace decode, every-token read arming, linked templates/EOS, epoch-owned poisoned root or native fallback refusal. The first submitted job nevertheless exposed an over-restrictive phase assertion. Astra confirmed from the pinned runtime that restore sets phase0 while at_boundary accepts0or1. The corrected harness retains all other root/rollback checks; [the failed attempt](ATTEMPTS.md) remains incomplete evidence.

After execution Astra independently verified all76source hashes,1,107raw hashes/extents totaling27,901,765bytes,445transition/token/history chains, and every byte scale/code reconstructed from original span data. Audit source K/V and both float banks match the predecessor byte for byte. The recorded poison digest matches exactly69,632bytes of the declared quiet-NaN pattern. Exact34 queries, sparse ports, full readouts and complement-cache metadata agree with native while raw poisoned hashes correctly differ.

Independent FP64 summation over all1,068byte head reads reproduces mean Z ratio0.9984137254620354, numerator error0.02086164598499982 and span-mean error0.013334995298044737; maximum row-field discrepancy is4.54e-15. Independent full-logit comparisons reproduce0.0932%,0.0855%,0.0333%,0.0675%,0.0734%,0.0612%. Byte worst numerator error12.82% and worst span-mean error5.42% remain visible. The centroid's first recall logits are slightly worse than deletion:4.5993%versus4.3357%.

All445Q17arrays match native. With unchanged earlier layers and identical token histories, this cut does not exercise changed queries feeding back into the selected layer. Upper-layer state still evolves under repeated altered reads. All policies, including deletion, preserve the three answers; the behavior is nondiscriminating about this span's necessity.

Astra supported the saved-only same-environment reproducibility repair: preserve the local strict refusal, authenticate raw/source/runtime identities and require exact canonical analysis-byte equality in the original environment. Independent FP64 centroid means0.6178607972286415/0.48438213448297535/0.3583174290350327 confirm that Linux/local FP32 log-count differences do not change the scientific magnitudes. This is not cross-platform exact arithmetic. No quality threshold is relaxed and no model rerun is needed for that audit.

The [mathematical note](MATH.md) has valid Gaussian/affine closure and quantized softmax bounds under their stated ideal-arithmetic assumptions. Equal-key merging must retain multiplicity as well as summed values. Continuous-state error recurrence assumes common inputs; token divergence needs an input-mismatch term or switched-system treatment. These wording clarifications are added after the frozen execution note without altering its snapshot.

The next proposed mechanism is own-state byte append: encode each actual positioned new K/V row, atomically advance encoded ownership, consume it at the current read as well as later reads, make the original unavailable after successful encoding, and bind rollback to the encoded cursor. This costs528bytes per layer/token versus2,048FP32bytes, plus allocation metadata/workspace, and still grows linearly with context. Original model/cache allocation, broader query feedback, stacked-layer composition and serving benefit remain open.
