# Vision: an executable account of model computation

## The target

We want to understand model computations well enough to replace expensive parts with executable programs. Such a program must obtain its inputs, transform them, write consequential state, and remain usable when later computations consume that state. Names such as “symbol,” “memory” or “time circuit” are useful when they identify those executable relationships.

Let S be the native state, u an actual consumed input, θ the source model and π its numerical profile:

\[
S^+=F_{\theta,\pi}(S,u),\qquad \ell=R_{\theta,\pi}(S).
\]

For retained state c=C(S), a reduced executor seeks

\[
C(F(S,u))=G(C(S),u),\qquad R(S)=H(C(S)),
\]

or a measured approximate version for a declared consumer, input domain and horizon. The domain must include the states produced by the candidate's own tokens and later supplied inputs.

Closure alone does not establish a saving: C=identity and G=F already works. A useful program must account for its bootstrap, operand resolution, updates, reads, stored coefficients and original operations still called. It may retain full state while replacing some operators. Compact whole-chat state is not a prerequisite for every useful replacement.

## The simplifying assumption

Search for a **bounded-cost family of representations and operations closed under the reads, writes and queries actually admitted by the program**. Discarded information must either remain irrelevant to those consumers or have an explicit, measured approximation effect. One fixed tiny subspace for all possible conversations is not supported by current evidence.

For a supplied residual program

\[
x^+=x+D f(Ax,Bx,\|x\|^2),
\]

let the orthonormal rows of R span every admitted linear reader and every write direction. With z=Rx and κ=||(I−RᵀR)x||²,

\[
z^+=z+RDf(AR^Tz,BR^Tz,\|z\|^2+\kappa),\qquad\kappa^+=\kappa.
\]

The unread orientation remains unchanged, so retained coordinates and omitted energy close the nonlinear update in real arithmetic. This only reduces state when the required span and retained invariants are smaller than the original state. It also needs a separate finite-arithmetic qualification.

The completed known-wiring CUDA organism demonstrates a bounded finite instance and its failure mode: an off-space write makes omitted sign affect the next RMS scale; retaining that coordinate restores the tested trajectory. The original Qwen down-map rank bound also excludes ranks below 256 for this strong common-linear-space construction. Neither result forbids useful approximate or consumer-relative replacements. ## What the MLP work says

For normalized receiver x,

\[
M(x)=D[\operatorname{SiLU}(Gx)\odot Ux].
\]

We can reconstruct this operation, derive local response programs and replace one scalar stage on evolving inputs. We do not yet have a generally useful cheaper resolver for its complete live operands.

The source gate law improves every evaluated same-input write over deletion in two development conversations, while retaining all original G/U/down projections. The B3 program removes selected G/U work but loses information: equal executed coefficient/RMS codes can produce different native writes. Supplying omitted images repairs the write while paying the projections again.

This makes operand formation a concrete next reduction target. One proposed candidate freezes a shared input basis from the source gate/up operators, forms lower-width operands on each candidate's own receiver, retains exact SiLU, and counts the original maps actually omitted. A rank budget is an economic hypothesis, not an assumed exact rank or an accuracy gate. Native, deletion, existing B3 and matched-complexity controls help distinguish useful structure from more coordinates. The separately running Astra-advised experiment is outside this repository extraction; its result must be reported from its own sealed evidence.

## What the attention work says

For a fixed query,

\[
N(q)=\sum_j e^{q^Tk_j/\sqrt d}v_j,\qquad
Z(q)=\sum_j e^{q^Tk_j/\sqrt d},\qquad A(q)=N(q)/Z(q).
\]

Appending or changing a span has a compositional numerator/partition account. The completed C trace qualifies such an account on supplied native operands. A future query reweights the old keys. Retaining one N/Z pair does not determine that future read, and retaining the full response functions may cost as much as the original history.

A reusable span-response representation must preserve useful addressing, values and partition mass over the queries generated by its own state. For uniform μ and w(q)=exp(qᵀk/√d),

\[
A(q)-\mathbb E_\mu[V]
=\frac{\operatorname{Cov}_\mu(w(q),V)}{\mathbb E_\mu[w(q)]}.
\]

The small uniform summary drops this association. It advances exactly but loses the tested image behavior. Selective approximations retain useful behavior with measurable error. Exact state-law execution, native-state sufficiency and useful approximation are three distinct claims.

## Time circuits and the symbol table

The time circuit identifies ordered dependency instances: which state an operation reads, where it writes, and which later invocation consumes the result. A dynamic circuit binds active routes and operands in one context. A symbol-table entry should connect a qualified computation family to actual source factors, addresses, memory support, clocks and a numerical profile.

Serving includes the resolver:

\[
o_t=\operatorname{resolve}(c_t,u_t,\mathrm{law}),\qquad
c_{t+1}=G_{\mathrm{law}}(c_t,o_t).
\]

A tensor name is valuable for analysis, but obtaining it by running the replaced block does not save that block. Automatic family discovery, source algebra, semantic interpretation and a particular causal invocation remain separate layers of knowledge.

## Runtime improvements proposed

Retain C's existing execution order, parent ownership, cache and token authority. Extend it with narrow interfaces at demonstrated operation boundaries:

1. Separate immutable law mathematics, compiled program data, live invocation and state encoding. Bind actual operands and support to the correct parent and phase.
2. Keep cheap work counters separate from optional detailed tracing. Count original and derived maps, attention work, vocabulary projection, compilation, transfers, model/program/state bytes and replay. Full tensor hashes must not become mandatory hot-path synchronization.
3. Prevalidate static conditions before mutation. Stage experimental writes or return an explicit partial-state contract requiring replay. Record physical work even when logical state rolls back.
4. Separate token commitment from demanded readout. Intermediate supplied tokens can potentially commit K/V without an unused vocabulary projection, once pending/readout validity and checkpoint semantics are qualified. This is proposed dependency elimination, not an implemented optimization.
5. Preserve full-prefix and current-row distinctions. Add arbitrary cache installation or portable interior cuts only with an explicit state schema and demonstrated need.

The current full head costs 233,373,696 nominal MACs per call, about 15.12% of the reported native per-token linear work. Skipping unused prompt readouts could remove real ingestion work. This is neither a measured latency improvement nor a decode speedup claim.

## Gaps and the claim we want next

The major gaps are economical operand formation; query-qualified memory under updates; bootstrap from genuinely new inputs; composition across remaining layers and readout; and useful long continuation under the candidate's own history.

Local error and carried error interact. Returning to native equations on an approximate cache does not restore the native same-text state. Exact restoration needs a compatible ancestor and replay or an exact shadow, with their costs explicit. Preserve diverged branches as evidence rather than silently replacing them.

An independently justified infinity-norm logit error bound ε and a native top-two margin above 2ε preserve one greedy choice. A measured average error or the candidate's margin alone does not provide that bound. After token divergence, both branches must consume their own actual choices.

Native fidelity also differs from task quality: an exact emulator can reproduce a wrong arithmetic answer. Future results should report execution mechanics, native fidelity, task behavior, continuation and cost separately. The next bounded claim should identify the actual computation replaced and show what later consumer used its produced state, without elevating a local success into unrestricted chat emulation.
