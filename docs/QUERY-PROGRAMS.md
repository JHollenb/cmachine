# Explicit operand programs

The runtime now accepts immutable, model/layer-qualified Q/K/V programs through `qwen_qkv_program_init` and `qwen_qkv_bind`. At a selected layer the actual learned RMS-normalized receiver is encoded once, `z = B x`, and selected projections execute `y = H z`. Unselected maps remain native. The original model bias and RoPE execute once, afterward. A session can attach different programs at several layers; the runtime does not assume a basis or image is portable between layers.

Programs can be attached or removed only at an empty session, with no retained parents. They belong to the caller and must outlive every attached session. Initialize a zeroed object, free before reinitializing, and detach or destroy sessions before freeing the program. Program identity includes model digest, layer, rank, selected maps and numerical bytes. Physical operation counters survive checkpoint restoration. These counters cover attached operand programs, not all model work.

`qwen_lexical_compile` instead pays for a finite token-local first-layer table using the original embedding, learned RMS, Q/K/V projections and biases. Lookup supplies pre-RoPE Q/K/V; original RoPE and all subsequent computation remain. An explicit sorted subset is supported; a missing token refuses before session mutation. Passing no IDs and the complete vocabulary size compiles every token. There is no online cache fill. Tables may be saved and loaded with model/shape/content verification; the prototype format assumes little-endian 32-bit integers and IEEE FP32, matching the supported execution platform. The table is host-resident and transfers a row on each hit. Compilation and transfers are paid, separate costs. Token locality is an exact first-layer property, not a claim about contextual queries in later layers.

`src/prototype_attention.h` contains the authenticated 16-recent/16-prototype numerical memory law and a streaming query pullback. For counted softmax probabilities `p`, attention `a`, and output error `e`, it computes `J_q^T e = sum_r p_r k_r ((v_r-a)^T e) / sqrt(128)` in FP64 without materializing a covariance matrix. The carrier occupies 98,464 bytes for the pinned 2-KV/12-query-head specimen. It is an experimental approximation, not a sufficient-state theorem.

The memory kernel owns no session or checkpoint policy. Attach it through the existing cache callbacks and explicitly restore its mutable bytes when rewinding; a cursor alone cannot undo prototype merges. Programs and prototype memory are independent: a compiled query can use full memory, and a native query can read compact memory. This separation is necessary to diagnose query error versus missing history.

`make operand-mechanics` exercises multilayer full-rank parity, binding, replay, lexical coverage and tamper refusal, and the covariance pullback with a model-free fixture. It does not establish real-model quality or speed. Native execution remains the default; no program is enabled implicitly and no original model weights are removed.

The [Q/K causal cut](../research/query_key_cut/README.md) demonstrates one caller-owned prototype snapshot plus append-only full-key cursors and explicit logits restoration through these cache/checkpoint interfaces. It is a research backend, not an automatically enabled serving policy or general snapshot stack. Its exact current layer18 replay still leaves different attention19 when prior higher-layer cache was formed differently; installing a current operand program cannot silently repair that history.

The same study's [from-zero mask follow-up](../research/query_key_cut/ON_POLICY_PLAN.md) exercises existing Q-only and K-only binding at layer18, with the frozen layer17 program retained. Q-only/native keys preserves two known inventory trajectories while K-only/native queries does not; explanation fidelity worsens relative to layer17 alone. This is evidence for selecting maps independently and evaluating their repeated historical consequences, not a new default policy or fresh generalization qualification.
