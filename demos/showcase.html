04 / operand program

Replace one boundary, keep the consumer visible.

The compiled lexical demo uses the public Qwen program API. It looks up first-layer Q/K/V atoms for consumed IDs, then leaves the remaining native computation in place so the replacement can be judged at the full-vocabulary consumer.

Native path and replacement boundary

token IDs→first-layer Q/K/V lookup→RoPE + attention / MLP→27 native layers + head

The table is compiled offline from a source-covered trajectory. Original weights remain resident; table construction, transfers, and the native reference pass are paid. This is an exact historical readout, not held-out generalization or a broad speedup claim.
